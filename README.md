## Selected research

- **MACH / MetaVision-DB** — Co-developed a visual-language agent framework for metaphor reasoning and communication games; led dataset construction, concept–image alignment, schema validation, and manual review.
- **MapAgent** — Built a Qwen3-based indoor localisation agent combining Bluetooth signals, motion, and map evidence, with independent verification and deterministic fallback.
- **MetroHeight** — Built an iOS app and FastAPI backend for RGB-D cargo-height measurement using SAM 3 segmentation, gravity-aligned reconstruction, and local floor fitting.

## Selected projects
